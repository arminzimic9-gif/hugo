# Arena pilots v1

These concepts are the immutable image sources for the first human-pilot Meshy pass.
Both characters intentionally use the same charcoal technical undersuit language so
gear and exosuit parts can be layered consistently later.

## Male pilot

- Source: `assets/originals/imported/arena-pilots/pilot-male.png`
- Purpose: registration preview and A-pose image-to-3D source.
- Prompt: Original adult male systems engineer and combat pilot, believable athletic
  anatomy, original face and short practical dark hair. Close-fitting charcoal-black
  technical undersuit with subtle cyan luminous seam piping and neutral interface
  ports. No armor, exoskeleton, helmet, weapon, backpack, cable, logo or text. Clean
  symmetrical full-body A-pose, arms 35 degrees from torso, visible separated fingers,
  feet shoulder-width, front-facing near-orthographic studio view on uniform light gray.

## Runtime conventions

- Player forward: +Z
- Origin: bottom
- Scale: meters
- Meshy pose mode: A-pose
- Rigging is deliberately deferred until the unrigged textured GLBs are reviewed.
